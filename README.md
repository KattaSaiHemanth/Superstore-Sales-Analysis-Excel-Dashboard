# Superstore Sales Analysis & Excel Dashboard

## Project Overview

This project analyzes Superstore sales data using Microsoft Excel to understand sales performance, profitability, regional trends, category performance, and sub-category performance.

The project includes data cleaning, transformation, PivotTable analysis, KPI calculations, and an interactive Excel dashboard.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis

## Data Cleaning

The raw dataset was prepared before performing the analysis.

Key data-cleaning steps included:

- Removed duplicate records.
- Checked and organized the dataset for analysis.
- Converted Order Date values from numeric/incorrect formats into proper date format.
- Converted and validated date-related fields for time-based analysis.
- Checked important fields such as Sales, Profit, Quantity, Discount, Category, Sub-Category, Region, and Customer Segment.

## Analysis Performed

### 1. Monthly Sales Analysis
Analyzed sales performance across different months to identify sales trends and fluctuations throughout the year.

### 2. Regional Sales Analysis
Compared sales performance across the Central, East, South, and West regions.

### 3. Category Analysis
Analyzed sales across the major product categories:

- Furniture
- Office Supplies
- Technology

### 4. City & Sub-Category Analysis
Created a detailed PivotTable to analyze sales across cities and product sub-categories.

### 5. Sub-Category Profitability Analysis
Analyzed:

- Total Sales
- Total Profit
- Profit Margin

for individual sub-categories.

This helped identify both highly profitable and loss-making sub-categories.

## Key KPIs

- Total Sales: $4.64M
- Total Profit: $546.57K
- Overall Profit Margin: 11.77%

## Key Insights

- Technology generated the highest sales among the three major categories.
- Several Furniture sub-categories generated negative profit.
- Tables, Bookcases, Chairs, and Furnishings showed negative profitability in the analysis.
- Copiers and Phones were among the stronger-performing sub-categories in terms of profit.
- Sales performance varied across regions and months.

## Dashboard

The Excel dashboard provides an overview of:

- Monthly sales
- Regional sales
- Category sales
- City-level sales
- Sub-category sales
- Profitability
- Profit margin

## Project Outcome

The analysis demonstrates how Excel can be used to clean raw business data, calculate KPIs, identify trends, analyze profitability, and present business insights through interactive dashboards.
